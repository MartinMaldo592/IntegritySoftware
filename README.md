## 📌 Sobre el Proyecto

**Integrity Software** es la plataforma web corporativa de **Integrity Software S.A.C.**, diseñada para brindar soluciones tecnológicas accesibles y de alto impacto para micro y pequeñas empresas (MYPES) en el Perú. 

El proyecto cuenta con una arquitectura moderna migrada 100% a **TypeScript**, **Next.js 15** y **React 19**, incorporando un motor visual corporativo *Executive Light* con efectos de inclinación 3D, animaciones de parallax, carruseles horizontales adaptativos y simuladores en tiempo real.

---

## 🛠️ Tecnologías Utilizadas

- **Framework Principal:** Next.js 15 (App Router)
- **Lenguaje:** TypeScript 5.7+

- **Estilos & Diseño:** Vanilla CSS 3 (Glassmorphism, CSS Grid, Custom Properties, Responsive Layouts)

## ⚙️ Instalación y Ejecución Local

### Pre-requisitos
- Node.js (v18.x o superior)
- npm o yarn

### Pasos

1. **Clonar el repositorio:**
   ```bash
   git clone https://github.com/MartinMaldo592/IntegritySoftware.git
   cd IntegritySoftware
   ```

2. **Instalar dependencias:**
   ```bash
   npm install
   ```

3. **Iniciar el servidor de desarrollo:**
   ```bash
   npm run dev
   ```
   Abre [http://localhost:3005](http://localhost:3005) en tu navegador.

4. **Compilar para producción (TypeScript Check & Build):**
   ```bash
   npm run build
   ```
